The station can now send events to your own servers, such as a Home Assistant webhook trigger or an n8n workflow. Add an event destination with `POST /events/destinations` and its address; the answer carries the destination's signing secret, which is shown once (`POST /events/destinations/{id}/secret` makes a new one). `POST /events/destinations/{id}/test` sends it a test event and says what it answered, and `GET /events/destinations/{id}/deliveries` lists the latest attempts. Every delivery is a JSON POST signed in `Deadair-Webhook-Signature` with a timestamp in `Deadair-Webhook-Timestamp`. Addresses on your own network are fine; a redirect is never followed. The station sends `track.started` as a record begins, `talk.started` when it starts speaking, `production.started` when a phone-in or a guest begins, and `programme.started` for a podcast episode or a reading, each at the moment listeners hear it, so a light can follow what is on air. A destination can ask for only some of them (`events`, empty for all, `GET /events/types` for each with an example). An event that would arrive after its record has finished is dropped rather than sent late, and a destination that fails twenty deliveries in a row is turned off, with a line on the activity feed; turning it back on resets the count. The same operations are in every SDK; the routes that return a secret are not MCP tools.
