> What a date means where this station is: a name the presenters can say, and a mood to lean into on a
> day the show on air names none. `ruleKind` says when it falls, and which of the fields beside it count

<details>
<summary>Attributes (15)</summary>

| Attribute       | Type                                                                                   | Required | Description                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------- | -------------------------------------------------------------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`            | `string`                                                                               | Yes      | _read-only_                                                                                                                                                                                                                                                                                                                                                                                                    |
| `words`         | `string`                                                                               | Yes      | Said on air as written: `Halloween`, `the first day of Hanukkah`                                                                                                                                                                                                                                                                                                                                               |
| `ruleKind`      | `'fixed' \| 'weekday' \| 'easter' \| 'calendar' \| 'dates'`                            | Yes      | `fixed` is the same date every year, from `month` and `day`. `weekday` is the nth of a weekday in a month, from `month`, `ordinal` and `weekday`. `easter` is a number of days from Western Easter Sunday, from `offsetDays`. `calendar` is a date in the Hebrew or Islamic calendar, from `calendar`, `calendarMonth` and `day`. `dates` is the dates themselves, from `dates`, for what no rule can work out |
| `month`         | `number`                                                                               | No       |                                                                                                                                                                                                                                                                                                                                                                                                                |
| `day`           | `number`                                                                               | No       | The day of the month, in the rule's own calendar                                                                                                                                                                                                                                                                                                                                                               |
| `ordinal`       | `number`                                                                               | No       | Which of that weekday in the month: 1 to 5, or -1 for the last. The fourth Thursday of November is `4`                                                                                                                                                                                                                                                                                                         |
| `weekday`       | `number`                                                                               | No       | 0 is Sunday                                                                                                                                                                                                                                                                                                                                                                                                    |
| `offsetDays`    | `number`                                                                               | No       | Days from Easter Sunday: 0 is the day itself and -2 is Good Friday                                                                                                                                                                                                                                                                                                                                             |
| `calendar`      | `'hebrew' \| 'islamic-umalqura'`                                                       | No       | `islamic-umalqura` is calculated, so a community going by the sighted moon may keep the day a day either side of it                                                                                                                                                                                                                                                                                            |
| `calendarMonth` | `string`                                                                               | No       | The month in that calendar, as `calendars` lists it                                                                                                                                                                                                                                                                                                                                                            |
| `dates`         | `string[]`                                                                             | No       | As `YYYY-MM-DD`. These run out, so a list needs refreshing                                                                                                                                                                                                                                                                                                                                                     |
| `mood`          | `'love' \| 'happiness' \| 'comfort' \| 'sadness' \| 'loneliness' \| 'anger' \| 'fear'` | No       | What this day leans into, when the show on air names no mood of its own. Records a model has judged to be in it are a little more likely to be picked, and nothing is ever kept off the air for it. Absent leans nothing                                                                                                                                                                                       |
| `enabled`       | `boolean`                                                                              | Yes      | Whether the station knows about it. Off, it is never said and never leans anything                                                                                                                                                                                                                                                                                                                             |
| `position`      | `number`                                                                               | Yes      | Where it comes in the list. When two fall on one date the first wins. _read-only_                                                                                                                                                                                                                                                                                                                              |
| `nextDate`      | `string`                                                                               | No       | When it next falls, as `YYYY-MM-DD` on the station's calendar, counting today. Absent when it does not fall again, as a list of dates that has run out. _read-only_                                                                                                                                                                                                                                            |
