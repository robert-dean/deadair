> Which day a special comes round on. `ruleKind` says how, and which of the fields beside it count

<details>
<summary>Attributes (9)</summary>

| Attribute       | Type                                                        | Required | Description                                                                                                                                                                                                                                                                                                                                                                     |
| --------------- | ----------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ruleKind`      | `'fixed' \| 'weekday' \| 'easter' \| 'calendar' \| 'dates'` | Yes      | `fixed` is the same date every year, from `month` and `day`. `weekday` is the nth of a weekday in a month, from `month`, `ordinal` and `weekday`. `easter` is so many days from Western Easter Sunday, from `offsetDays`. `calendar` is a date in another calendar, from `calendar`, `calendarMonth` and `day`. `dates` is a list of dates, for what none of those can work out |
| `month`         | `number`                                                    | No       |                                                                                                                                                                                                                                                                                                                                                                                 |
| `day`           | `number`                                                    | No       | The day of the month, in the rule's own calendar                                                                                                                                                                                                                                                                                                                                |
| `ordinal`       | `number`                                                    | No       | Which of that weekday in the month: 1 to 5, or -1 for the last. The fourth Thursday of November is `4`                                                                                                                                                                                                                                                                          |
| `weekday`       | `number`                                                    | No       | 0 is Sunday                                                                                                                                                                                                                                                                                                                                                                     |
| `offsetDays`    | `number`                                                    | No       | Days from Easter Sunday: 0 is the day itself and -2 is Good Friday                                                                                                                                                                                                                                                                                                              |
| `calendar`      | `'hebrew' \| 'islamic-umalqura'`                            | No       | `islamic-umalqura` is calculated, so a community going by the sighted moon may keep the day a day either side of it                                                                                                                                                                                                                                                             |
| `calendarMonth` | `string`                                                    | No       | The month in that calendar, as `GET /schedule/occasions` lists them                                                                                                                                                                                                                                                                                                             |
| `dates`         | `string[]`                                                  | No       | As `YYYY-MM-DD`. These run out, so a list needs refreshing                                                                                                                                                                                                                                                                                                                      |

</details>
