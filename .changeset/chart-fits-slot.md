A chart airing inside a scheduled block is cut to fit the time the block has left, keeping the top of the chart, so a countdown reaches number one before the next show starts instead of being cut off halfway. A one-hour block is roughly a top fourteen and a five-hour block a top seventy, from the same chart. A twentieth of the time, about what the station's talk measures, is held back for the host when the show takes breaks. A station with no schedule still airs the whole chart.
