> Who the station is when it opens its mouth: the character a model writes in, the phrasings underneath it, the voice that says them, and what it plays

<details>
<summary>Attributes (22)</summary>

| Attribute        | Type                                                                | Required | Description                                                                                                                                                                                                                                                                                                                                      |
| ---------------- | ------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`             | `string`                                                            | Yes      | _read-only_                                                                                                                                                                                                                                                                                                                                      |
| `key`            | `string`                                                            | Yes      | A stable slug, unique per station. What a log line names and what a seeded persona is recognised by                                                                                                                                                                                                                                              |
| `kind`           | `'host' \| 'caller'`                                                | No       | What this character is FOR. `host` is the station's own voice; a `caller` phones in to a production, is cast per programme, and can never be put on air. Absent means `host`, so a form written before callers existed still means what it meant                                                                                                 |
| `label`          | `string`                                                            | Yes      |                                                                                                                                                                                                                                                                                                                                                  |
| `style`          | `string`                                                            | Yes      | Completes "You are …". Who they ARE; the sheet below carries how they talk                                                                                                                                                                                                                                                                       |
| `djName`         | `string`                                                            | No       | The name this character goes by on air, overriding the station's own while it is active                                                                                                                                                                                                                                                          |
| `voice`          | `string`                                                            | No       | The station voice that speaks this persona, as the id a speech plugin maps. Empty means that plugin's default                                                                                                                                                                                                                                    |
| `soundboard`     | `string`                                                            | No       | The soundboard this character has to hand, as the name of a board in the pad library. Empty for a presenter who works without one. What reaches a model is the names of the pads on that board, never this word                                                                                                                                  |
| `diction`        | `string[]`                                                          | No       | The dialect: grammar and substitutions that apply to every sentence rather than to a subject                                                                                                                                                                                                                                                     |
| `dictionMarkers` | `string[]`                                                          | No       | Words whose presence proves the dialect survived. What a model's answer is checked against                                                                                                                                                                                                                                                       |
| `quirks`         | `string[]`                                                          | No       | What they always and never do on air                                                                                                                                                                                                                                                                                                             |
| `preoccupations` | `string[]`                                                          | No       | The standing subjects they keep coming back to. Exactly ONE reaches any one break, chosen by rotation, which is what makes a character sound like it has things on its mind rather than one thing                                                                                                                                                |
| `catchphrases`   | `string[]`                                                          | No       | Signature phrases, asked for sparingly                                                                                                                                                                                                                                                                                                           |
| `avoid`          | `string[]`                                                          | No       | Wording that breaks the character                                                                                                                                                                                                                                                                                                                |
| `background`     | `string`                                                            | No       | A couple of grounded facts they may self-reference                                                                                                                                                                                                                                                                                               |
| `brevity`        | `'short' \| 'one-line'`                                             | No       | How much this character says. Absent for the station's ordinary length; the rung above it is `latitude`, which is a different kind of thing rather than a longer one                                                                                                                                                                             |
| `latitude`       | `'loose' \| 'unleashed'`                                            | No       | How much room this character is given, above the station's ordinary discipline: a bigger word ceiling, a licence to follow the thought instead of making one point, and at `unleashed` no restraint on how it says it. Offered only by the ordinary talk break, always outranked by the station's content policy, and it switches off no refusal |
| `chattiness`     | `'reserved' \| 'sparing' \| 'ordinary' \| 'chatty' \| 'relentless'` | No       | How often this character talks, as a scale on the station's own interval between breaks. Absent is `ordinary`, which is that interval unchanged. The quietest rung is half as often and never silence: turning the station's breaks off is a station setting, and two switches for one thing can disagree                                        |
| `storytelling`   | `'never' \| 'occasionally' \| 'often'`                              | No       | How readily this character works one of its own stories into an ordinary talk break. Absent is `occasionally`, which offers one only where the station knows nothing about the records either side. The stories themselves are their own list, and a `story` band on the clock outranks this whatever it says                                    |
| `samples`        | `string[]`                                                          | No       | Lines in their own voice, used as examples and as a console preview                                                                                                                                                                                                                                                                              |
| `templates`      | `string`                                                            | No       | This character's own break phrasings, one per line. Empty means the station's global ones                                                                                                                                                                                                                                                        |
| `active`         | `boolean`                                                           | Yes      | Whether this is the one on air. At most one per station. _read-only_                                                                                                                                                                                                                                                                             |
