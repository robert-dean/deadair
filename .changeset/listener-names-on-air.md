A dedication no longer says a listener-typed name that is not a name or that passes for the station's own. A name with no letters, one longer than a name, an address, or one that contains the station's name, its presenter's or a persona's (even with accents, a zero-width character or look-alike Cyrillic or Greek letters slipped in) is now said as "a listener", and a dedication to such a name leaves the name out. The request itself is placed exactly as before. A zero-width character inside a name no longer splits it into separate words on air, a chat display name is tidied and held to the same length an app's name is, and the check that stops the presenter reading a listener's message out word for word is no longer slipped by a curly apostrophe.
