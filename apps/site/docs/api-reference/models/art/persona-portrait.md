> A presenter's picture, which a listener's player shows while that persona is on air

<details>
<summary>Attributes (2)</summary>

| Attribute   | Type     | Required | Description                                                                                                        |
| ----------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------ |
| `personaId` | `string` | Yes      | The persona it belongs to                                                                                          |
| `url`       | `string` | Yes      | Where the station serves it, as a path under the API root. The same shape and the same route a record's cover uses |

</details>
