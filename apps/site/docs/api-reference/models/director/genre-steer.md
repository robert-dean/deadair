> A lean toward some genres for a while. The opposite of a rule: the station favours them when it
> chooses records, and still plays anything else rather than run dry

<details>
<summary>Attributes (2)</summary>

| Attribute | Type       | Required | Description                                                                                 |
| --------- | ---------- | -------- | ------------------------------------------------------------------------------------------- |
| `genres`  | `string[]` | Yes      | What to favour, as genres. A record tagged with any of them, or a kind of one, is preferred |
| `endsAt`  | `string`   | Yes      | When the station goes back to choosing as it ordinarily does                                |

</details>
