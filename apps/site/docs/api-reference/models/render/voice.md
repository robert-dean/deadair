> A voice the station can be asked to speak in

<details>
<summary>Attributes (3)</summary>

| Attribute     | Type     | Required | Description                                                               |
| ------------- | -------- | -------- | ------------------------------------------------------------------------- |
| `id`          | `string` | Yes      | What to pass as a segment's `voice`. Empty means the plugin's own default |
| `label`       | `string` | Yes      | What the console calls it                                                 |
| `description` | `string` | No       | What it sounds like, or what it maps to on the engine                     |

</details>
