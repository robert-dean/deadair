A word inside a record's title does not count                                                                                                                                                                                       |

| `growth`            | `'proposes' \| 'self-directed'`                                     | No       | Whether the nightly passes may write this character new material outright, or only ever propose it for you to accept. | `trivia`            | `'keen'`                                                            | No       | How much this character leans on what the station knows about a record. Offered only by the ordinary talk break, and the grounding rules do not move: it may still say only what a note says |

Deleting a host unties the caller rather than silencing them. Saving a caller without it clears its ties                                                                                                            |
