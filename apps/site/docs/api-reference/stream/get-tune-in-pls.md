The station's streams as a PLS playlist, MP3 first, for a player that takes a playlist file rather than a stream address

**`GET`** `/listen.pls`

:::note
SDK method: `getTuneInPls`
Security: public
:::

## Response

`200 OK` — Returns `string`.

`404 Not Found`
