A fourth voice: the station can speak through ElevenLabs. Enable the ElevenLabs plugin, paste an API key, and map the station's voices onto ElevenLabs voice ids. Each voice can set its own Stability, Similarity, Style and Speed; a setting the chosen model does not read is not sent. The model defaults to Eleven v4. A spent quota stops the plugin with a message saying so, rather than retrying.
