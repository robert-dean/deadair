> What an open invitation is for, shown to the person before they accept

<details>
<summary>Attributes (4)</summary>

| Attribute     | Type           | Required | Description                       |
| ------------- | -------------- | -------- | --------------------------------- |
| `email`       | `string`       | Yes      | The address the account will have |
| `role`        | `PlatformRole` | Yes      | The role it will hold             |
| `stationName` | `string`       | Yes      | What the station calls itself     |
| `expiresAt`   | `string`       | Yes      | When the link stops working       |

</details>
