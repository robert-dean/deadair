On a station set to a language other than English, the station's built-in English phrasings are no longer used. These are the lines it falls back on when no model wrote the break. Your own phrasings and a persona's still are, as long as they don't use the time or the greeting, which the station can only fill in English. With none, the break is left out: a warm-up, a jingle or a dedication plays only if somebody has written a line for it in the station's language.
